# 🤖 Basic AI Agent

A simple AI agent built using **LangChain, Google Gemini, and Streamlit**. It can answer user questions, search the web, and retrieve current weather information.

## 🚀 Features
- AI-powered conversations using Google Gemini
- Web search using DuckDuckGo
- Current weather information using Weatherstack API
- Interactive chat interface built with Streamlit

## 🛠️ Tech Stack
- Python
- LangChain
- Google Gemini API
- Streamlit
- DuckDuckGo Search
- Weatherstack API

## ⚙️ How It Works
1. The user enters a question in the chat interface.
2. The AI agent decides whether to answer directly or use a tool.
3. It can search the web or fetch weather information.
4. The agent returns the result to the user.

## ▶️ Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

Configure `GOOGLE_API_KEY` and `WEATHER_API_KEY` as environment secrets before running the app.
